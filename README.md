🏨 Cairo Hotel — Luxury Hospitality Web Application
  Cairo Hotel is a modern, responsive front-end web application built with React, designed to showcase a luxury hotel experience. It provides visitors with a seamless interface to explore accommodations, browse hotel amenities, view high-resolution photo galleries, read guest testimonials, and initiate room reservations.

✨ Key Features
  Hero & Quick Booking Bar: Captivating landing section paired with an interactive booking bar (Hero, BookingBar) for seamless reservation inquiries.
  Room Showcase & Interactive Modals: Browse available suites and rooms (Rooms) with detailed pop-up modals (RoomModal) displaying pricing, features, and room specifics.  
  Amenities & Visual Gallery: Dedicated sections showcasing luxury facilities (Amenities) alongside a curated photo gallery (Gallery).
  About & Guest Testimonials: Storytelling section (About) paired with authentic visitor reviews (Testimonials) to build trust.
  Responsive Navigation & Contact: Smooth navigation (Navbar), direct inquiry section (Contact), and a comprehensive site footer (Footer).

🛠️ Tech Stack
  Frontend Framework: React.js (JSX)
  Styling: Custom Modular CSS3 (Component-scoped stylesheets)
  Data Management: Structured JavaScript data modules (hotelData.js)
